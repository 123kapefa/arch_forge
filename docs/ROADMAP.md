# ROADMAP — arch_forge

Путь к продукту. Фазы: **1 видеть · 2 действовать · 3 контроль**. Вижен — `VISION.md`, решения — `docs/adr/`.

## Где мы сейчас (arch_forge, проверено на `auth_service`)

Бэк на .NET по своду + свой фронт (`adr/0009`, `adr/0010`):

- **Analysis** — Roslyn: **семантика** (`Compilation` из готового `bin/` — транзитивное наследование/ссылки) + синтаксический пол при сбое (`adr/0008`); `путь → IR`. Типы, роли по convention-pack, дрейф, честное покрытие. `GET /api/analysis`.
- **Map** — фронт-гейтвей к Analysis (типизированный `AnalysisClient`) + проекции focus/слой. `GET /api/map`.
- **Свой вьюер** (React + React Flow): плашки с ролями/слоями/честностью, связи `uses/holds/implements/raises/handles`, проекции слой + focus, тумблеры «без tests/одиночек». На `auth_service`: 49 узлов / 42 связи, покрытие 49 эвристика / 0 unknown, 4 дрейфа.
- **Репо:** приватный GitHub, флоу `main` (готовые фазы) ← PR ← `dev` (интеграция Фазы 1) ← PR ← `feature/*`.
- **Дальше:** уровни System→Service (сейчас single-service, `adr/0004`) и «члены типа»; импорт пользовательского пака из свода (сейчас встроенный `Default()`); транзитивные импорты и «тяжесть»; серверные лимиты масштаба; поиск.

## Фаза 1 — Видеть (цель: DoD из VISION)

Декомпозиция и статусы — `docs/plan-phase-1.md`.

- **P1-A Ядро анализа (Analysis)** — *сделано* — Roslyn floor → роли по паку + дрейф + покрытие + тип-граф (`holds/implements/uses`); контракт IR.
- **P1-B Свой вьюер (frontend)** — *сделано, MVP* — плашки, связи, проекции слой/focus, тумблеры, честное покрытие (`adr/0010`).
- **P1-C Семантика Roslyn** — *сделано* — `Compilation` из `bin/`-ссылок (обход строгого build): транзитивное наследование/дженерики + рёбра `uses/holds/raises/handles`; на `auth_service` рёбер 31→42, `unknown` 3→0. Оппортунистично (fallback на синтаксический пол).
- **P1-D Навигация уровней** — *сделано* — drill Layer→Type + хлебные крошки, переключение обзор/типы. Уровни System→Service (мульти-сервис) и «члены типа» — вне текущего скоупа (single-service, `adr/0004`).
- **P1-E Инспектор + якорь на исходник** — *сделано* — панель узла (роль, слой, дрейф, зависимости) + «открыть в коде» (`vscode://`).
- **P1-F Линт-панель** — *сделано* — отклонения от свода списком + подсветка нарушений направления слоёв (на полном графе, tests игнорируются).
- **P1-G Импорты за кнопкой** — *сделано, слайс 1* — прямые пакеты: версии, кто использует, конфликты версий. Транзитивы + «тяжесть» (`project.assets.json`) — слайс 2.
- **P1-H Робастность** — *сделано частично* — изоляция ошибок по файлам, исключение `bin/obj/generated`, пропуск гигантских файлов, кап семантики, сквозная отмена (`CancellationToken`) + таймауты на фронте. **Не сделано** (follow-up): импорт пользовательского пака из свода (сейчас встроенный `ConventionPack.Default()`) и серверные лимиты масштаба.
