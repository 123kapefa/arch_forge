# ROADMAP — arch_forge

Путь к продукту. Фазы: **1 видеть · 2 действовать · 3 контроль**. Вижен — `VISION.md`, решения — `docs/adr/`.

## Где мы сейчас (arch_forge, проверено на `auth_service`)

Бэк на .NET по своду + свой фронт (`adr/0009`, `adr/0010`):

- **Analysis** — Roslyn (синтаксический разбор, `adr/0008`): `путь → IR`. Типы, роли по convention-pack, дрейф, честное покрытие. `GET /api/analysis`.
- **Map** — фронт-гейтвей к Analysis (типизированный `AnalysisClient`) + проекции focus/слой. `GET /api/map`.
- **Свой вьюер** (React + React Flow): плашки с ролями/слоями/честностью, связи `uses/holds/implements`, проекции слой + focus, тумблеры «без tests/одиночек». На `auth_service`: 49 узлов / 31 связь, покрытие 46 эвристика / 3 unknown, 4 дрейфа.
- **Репо:** приватный GitHub, флоу `main` (готовые фазы) ← PR ← `dev` (интеграция Фазы 1) ← PR ← `feature/*`.
- **Пробелы:** семантика Roslyn (пока только синтаксический пол); навигация System→Service→Layer (drill); якорь-на-исходник (клик→код); панель линта/инспектор; импорты; поиск/крупный масштаб.

## Фаза 1 — Видеть (цель: DoD из VISION)

Декомпозиция и статусы — `docs/plan-phase-1.md`.

- **P1-A Ядро анализа (Analysis)** — *сделано* — Roslyn floor → роли по паку + дрейф + покрытие + тип-граф (`holds/implements/uses`); контракт IR.
- **P1-B Свой вьюер (frontend)** — *сделано, MVP* — плашки, связи, проекции слой/focus, тумблеры, честное покрытие (`adr/0010`).
- **P1-C Семантика Roslyn** — `Compilation`/символы на собираемых проектах: точное наследование/дженерики/ссылки → меньше `unknown`, рёбра `raises/handles`.
- **P1-D Навигация уровней** — System→Service→Layer→Type→Member, хлебные крошки, drill-in.
- **P1-E Инспектор + якорь на исходник** — панель узла (роль, дрейф, зависимости) + «открыть в коде».
- **P1-F Линт-панель** — отклонения от свода списком, подсветка нарушений направления слоёв.
- **P1-G Импорты за кнопкой** — дерево библиотек + «тяжесть» (дубли версий, кто ещё использует).
- **P1-H Робастность** — изоляция ошибок по файлам, исключение `bin/obj/generated`, укрощение масштаба, таймауты; пользовательский пак из свода.
