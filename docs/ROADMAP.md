- **Analysis** (`:5100`) — Roslyn: семантика (`Compilation` из `bin/`) + синтаксический пол (`adr/0008`); роли по convention-pack, дрейф, покрытие. Эндпоинты: `GET /api/analysis` (типы), `GET /api/system?path&env&drift&layers&calls` (картина системы), `GET /api/imports`.
- **Системный слой** — разбор docker-compose (порты/сети/healthcheck, `override.yml`, именованные среды `?env=`, `env_file`/`.env`, строки подключения), узлы `service/datastore/topic/external`, рёбра `rw-db/http-call/pub-sub`, call-graph из кода (абсолютные URL), детекторы проблем: общая БД, цикл сервисов, висячее событие, БД наружу, дрейф, нарушения слоёв, DTO-маппинг.
- **Map** (`:5200`) — гейтвей к Analysis (`AnalysisClient`): `/api/map`, `/api/system`, `/api/imports`, `/api/fs`, `/api/git`.
- **Фронт** (React + React Flow, `:5173`) — доска «картина системы» (L0 Система → L1 Сервис → L2 Слой → типы/члены), переключатель сред, Deploy-вид, панель проблем, инспектор с провенансом, импорты, просмотр свода.
- **Масштаб:** ~4,5 тыс. строк C# в проде, 385+ тестов бэка, 67 тестов фронта.
- **Репо:** приватный GitHub, трекер — GitHub Project #2 (`docs/agents/issue-tracker.md`). Флоу: `main` ← PR ← `dev` ← PR ← `feat/*`.
- **Известные красные тесты:** 2 теста Analysis зависят от внешнего локального репозитория `auth_service`, который меняется (см. `docs/agents/known-issues.md`).
- **Дальше:** эпики Фазы 1.6 — `docs/roadmap-epics.md` (источник правды по статусам); профили и уровни настроек и авторизация — новые ADR (см. «Планируется»).

## Планируется (обсуждается, ADR ещё нет)

- **Профили и уровни настроек.** Сейчас пороги и списки суффиксов зашиты в код детекторов, а правила свода задаются JSON-файлом в целевом проекте, исходный свод рассчитан на крупные платформы. Нужны уровни (малый проект → полный свод), настройка через UI и хранение профиля в приложении.
- **Авторизация и пользователи.** Подключить отдельный сервис входа платформы (`auth-service-sandbox`, Keycloak) для аутентификации, управления пользователями и, возможно, подписок. Требует пересмотра `adr/0002` («локальное приложение, код не уходит»).
