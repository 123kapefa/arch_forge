# ROADMAP — arch_forge

От текущего `archlens` к продукту. Фазы: **1 видеть · 2 действовать · 3 контроль**. Вижен — `VISION.md`.

## Где мы сейчас (archlens, проверено на живых данных)

- Сервисы: `compose` + k8s + Dockerfile + по структуре кода; связи: `depends` / URL-в-коде / k8s ConfigMap; события pub/sub.
- Слои .NET из `ProjectReference` + конвенции (на CRM — 65 слоёв / 129 связей, направления верны).
- Импорты: дерево транзитивов + «тяжесть» + дубли версий.
- Мультипроект; API-сервер; каркас React-клиента.
- **Пробелы:** клиент сырой (God-компонент, drill-in неполный), нет тип-уровня, нет convention-pack/линта, нет ИИ.

## Фаза 1 — Видеть (цель: DoD из VISION)

Порядок милстонов (риск-первым — прототипы P1-3/P1-4). Декомпозиция на задачи — `docs/plan-phase-1.md`.

- **P1-1 Клиент до продукта** — навигация System→Service→Layer (клик-провал, хлебные крошки), чистка мёртвого пласта / God-компонента.
- **P1-2 Раскладка по слоям** — layout inner→outer (роль → дорожка) вместо force; направление к Domain; подсветка нарушений слоёв.
- **P1-3 Convention-pack: роли** *(прототип-риск)* — движок стереотипов по маркерам + встроенный дефолт-пак (MediatR/FluentValidation/ASP.NET/EF); импорт пака из свода команды. Роли на плашках.
- **P1-4 Тип-уровень (.NET / Roslyn)** *(прототип-риск)* — типы + связи `holds/implements/raises/handles`; drill в тип.
- **P1-5 Линт + инспектор** — отклонения от пака (панель); инспектор узла (роль, якорь, «открыть в коде», зависимости, статус).
- **P1-6 Покрытие + фильтры/focus** — отчёт маркеры/эвристика/unknown; фильтры тесты/либы; focus-окрестность.
- **P1-7 Робастность** — изоляция ошибок по файлам, исключение `bin/obj/generated`, укрощение масштаба (collapse/группировка), таймауты.
