# Трекер задач

Настройка конкретного репозитория: процесс задач и веток.

- **Трекер:** отдельного нет; задачи ведутся по вехам `docs/ROADMAP.md` / `docs/plan-phase-1.md`.
- **Репозиторий:** приватный `github.com/123kapefa/arch_forge`.
- **Ветки:**
  - `main` — защищённая; только готовые фазы (вливается по завершении фазы).
  - `dev` — интеграционная ветка текущей фазы (Фаза 1); сюда льются PR.
  - `feature/<slug>` (а также `feat/…`, `docs/…`, `fix/…`) — рабочие ветки.
- **PR:** рабочая ветка → `dev` (ревью там же); `dev` → `main` — по завершении фазы.
- **Commit-политика:** сообщения по-русски, кратко/по делу; область в префиксе (`Фронт:`, `docs:`, …); без секретов; trailer `Co-Authored-By` для ИИ-коммитов.
- **Прямой push** в `main`/`master` запрещён (правило `git-workflow`, hook `protected_branches`).

Агент следует этому процессу (правило `git-workflow`), а не универсальному flow.
