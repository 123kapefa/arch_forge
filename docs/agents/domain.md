# Домен

Настройка конкретного репозитория: доменные особенности, которые не выводятся из кода. Полный замысел — в `../VISION.md`, словарь — в `../../CONTEXT.md`.

- **Основные сущности:** Целевой проект, Сервис, Слой, Проект (`.csproj`), Плашка/Узел, Связь, Карта (определения — в `CONTEXT.md`).
- **Внешние системы:** локальные ИИ-провайдеры пользователя (Claude CLI, Codex CLI, Ollama/локальная модель) — Фаза 2; лицензионный бэкенд — при монетизации (будущее).
- **Особые правила:** целевой код не покидает машину; разбор только читает целевой проект, запись — лишь с явным апрувом пользователя (Фаза 2).

Общий язык и определения терминов — в `CONTEXT.md`. Здесь — репозиторий-специфичные детали.
