# Обзор

Главный экран нового интерфейса (`/overview`): не карта, а ответы на три вопроса — что не так, что это за система, насколько можно верить разбору. Карта служит доказательством и открывается отсюда одним кликом.

## Какой проект показывается
Путь проекта берётся из адреса (`/overview?path=<папка проекта>`), иначе из последнего открытого на карте проекта. Если пути нет, экран объясняет это и ведёт на `/map`: выбор папки пока там. Анализ запускается с проверкой слоёв, дрейфа и вызовов (находки и покрытие приходят только с ними), поэтому большой проект грузится дольше — пока виден скелет.

## Что на экране
| Блок | Что показывает |
|---|---|
| **Что не так** | все находки по важности: критично → предупреждение → покрытие → инфо; внутри уровня выше та, в которой бэк увереннее (если уверенность не применима — например, факт из compose, — находка не опускается ниже оценочных), и архитектурные раньше расхождений со сводом (метка «Свод»). У каждой — файл:строка (если бэк его дал, путь от корня проекта), правило, источник и уверенность в процентах; если бэк уверенность не указал, так и написано. Показаны первые 8, остальные по кнопке. Клик ведёт на `/problems/:id` |
| **Менять осторожно** | заглушка: данных о радиусе взрыва типов в API пока нет, блок появится вместе с экраном «Влияние» |
| **Что это** | мини-карта (до 14 узлов: сначала проблемные и самые связанные; остальные — «и ещё N на карте»), паспорт числами (сервисы, хранилища, шины, внешние системы, endpoint-ы, связи) и слои. Мини-карта целиком кликабельна → `/map`. Состояние узла передаётся не только цветом: предупреждение — пунктирная рамка, критично — толстая |
| **Насколько верить** | доли покрытия типов (от суммы с известным источником, в сумме 100%, малые — «<1%»): по маркеру (точно) / эвристика / неизвестно — суммарно и по сервисам; пишется, сколько сервисов вошло в покрытие из общего числа (неразобранные в доли не входят) (сначала с наибольшей долей неизвестного), список «что не разобралось» (усечённый разбор, «DI не прочитан», «синтаксический пол» и другие деградации бэка) |

## Честность
- Если есть деградации, сверху показывается баннер: разбор неполный, отсутствие находок не значит, что проблем нет.
- Нет находок и разбор неполный (или доли покрытия неизвестны) — блок «Что не так» прямо говорит, что это не «чисто».
- Нет разбивки по источнику (структурный скан без анализа кода) — вместо процентов пишется «доли неизвестны», а не нули.

## Состояния
Загрузка (скелет), ошибка (короткое сообщение сервера и «Повторить»), нет проекта, пустой проект (0 узлов — вероятно, указана не корневая папка), частичный разбор (баннер).

## Доступность
Один `<h1>`, блоки — регионы с заголовками, находки — список ссылок; серьёзность — значок и текст, не только цвет; светлая и тёмная темы.
