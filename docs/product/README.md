# arch_forge — что это и что умеет

arch_forge статически разбирает чужой C#/.NET-проект (Clean Architecture, микросервисы) и показывает его архитектуру картой: плашки типов, сервисов, баз и связи между ними. Разбор идёт через Roslyn и **не требует, чтобы разбираемый проект собирался**.

Эта область описывает только то, что работает сейчас (состояние ветки `dev`). Планы, причины решений и идеи — в [технической области](../tech/README.md).

## Принципы
- Код разбираемого проекта не покидает вашу машину.
- Разбор только читает: ничего не меняет в чужом репозитории.
- Всегда показывается хоть что-то: если часть кода разобрать не удалось, это видно как «не разобрано», а не выдумывается.
- Библиотеки не рисуются на карте, они вынесены на отдельный экран «Импорты».
