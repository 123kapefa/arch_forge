# 0010 — Свой фронт-клиент: React + React Flow (@xyflow/react), не reuse archlens

## Статус
Принято (2026-08-14). Уточняет фронт-часть [0009](0009-dotnet-roslyn-microservices.md); опирается на [0002](0002-local-web-app.md).

## Контекст
0009 упоминал фронт как «переиспользуем клиент archlens». Это неверно: archlens — **чужой репозиторий** (другого человека), для нас — только референс идей (IR-модель, «Импорты за кнопкой», раскладка), а не кодовая база. Переиспользовать/копировать его клиент нельзя. При этом бэк уже отдаёт стабильный контракт графа (`Map` → `/api/map`, IR из `ArchForge.Contracts`), на котором можно собрать собственный вьюер.

## Решение
- **Свой клиент**, написанный с нуля в `frontend/`, на контракте `Map` (`/api/map`). Код archlens **не копируется** — только идеи.
- **Стек:** Vite + React + TypeScript + **React Flow** (`@xyflow/react`, React Flow 12) для узлового графа + **`@dagrejs/dagre`** для раскладки.
- **Узел — «плашка»**: слой/вид/роль-стереотип, бейдж честности (`marker`/`heuristic`/`unknown`), значок дрейфа; рёбра `uses`/`holds`/`implements` со стрелками и подписями.
- **Проекции «укрощения»** (адресуют перегруженность вида): фильтр по слою, focus по клику (узел + прямые соседи), клиентские тумблеры «без tests / без одиночек». Раскладка: связный подграф — dagre LR, узлы-одиночки — сеткой по слоям.
- **Честность:** покрытие/дрейф — глобальные, не пересчитываются на срезе.
- **Дев-связка:** Vite-прокси `/api` → `Map` (`:5200`), без CORS; `Map` — единственная фронт-фейсинг точка (к `Analysis` фронт напрямую не ходит).

## Альтернативы
- **Reuse клиента archlens.** Отклонено: чужой репозиторий — код нельзя переиспользовать, только идеи.
- **`reactflow@11` (старый пакет).** Отклонено в пользу актуального `@xyflow/react` (React Flow 12).
- **Force-раскладка / elkjs.** Отложено: dagre проще и достаточно для тип-графа; одиночки решаются сеткой.

## Последствия
- Фронт эволюционирует как **свой** код (не «доводка archlens»); милстоны Фазы 1 (`ROADMAP.md`, `plan-phase-1.md`) переформулированы под него.
- Контракт `/api/map` — граница фронт/бэк: смена движка `Analysis` фронт не трогает.
- Десктоп-упаковка (`adr/0002`) остаётся достижимой поверх (локальный сервер + webview).
