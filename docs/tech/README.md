# Техническая область

Здесь лежит всё, что не описывает работающий продукт: дорога, причины решений, планы, идеи на будущее и технические справочники. Что работает сейчас — в [описании продукта](../product/README.md).

| Что | Где | Зачем |
|---|---|---|
| Замысел | [`VISION.md`](VISION.md) | северная звезда: проблема, замысел, позиционирование |
| Дорога | [`roadmap/ROADMAP.md`](roadmap/ROADMAP.md) | фазы и текущее состояние |
| Эпики | [`roadmap/epics.md`](roadmap/epics.md) | декомпозиция Фазы 1.6, статусы эпиков (источник правды) |
| Решения | [`adr/`](adr/) | почему сделано так, а не иначе; отвергнутые альтернативы |
| Идеи | [`ideas/`](ideas/README.md) | заделы, наблюдения, будущие мысли; созрели — становятся ADR или пунктом ROADMAP |
| Дизайн | [`design/`](design/prototype-notes.md) | заметки по прототипам и эталону интерфейса |
| Справочники | [`reference/`](reference/roslyn.md) | как устроена библиотека, на которой стоит движок |
| Архив | [`archive/`](archive/) | выполненные планы фаз (исторические, действующими не считать) |
| Для ИИ-агентов | [`agents/`](agents/) | трекер задач, доменные особенности, известные проблемы |

## Правила
- Решение, которое нелегко отменить, оформляется ADR (`adr/NNNN-slug.md`). Принятый ADR не переписывается: его заменяет новый.
- Идея живёт в `ideas/`, пока не стала решением. Идеи не описывают работающее.
- Изменилось поведение продукта — обновите [описание продукта](../product/README.md) в том же PR (`adr/0015`).
- Выполненный план уходит в `archive/`.
