# Режим «без сервера входа»

**Сейчас.** Вне окружения `Development` Map не стартует без `Authentication:Authority` и `Audience` (`adr/0013`): нужен какой-то OIDC-сервер. Режим разработки (`DevMode`) разрешён только в `Development`.

**Идея.** Для одиночного локального использования (один пользователь, одна машина, без подписок) нужен явный режим «без входа» вне разработки: без сервера входа, с понятным значком в шапке.

**Что мешает.** Решение по контролю доступа: «хоть как-то контролировать доступ» (требование к режиму разработки) пришлось бы распространить на постоянный режим; нужен способ не открыть Map наружу (loopback, запрет за прокси).

**Варианты.** (1) `Authentication:Mode=Local` с теми же ограничениями, что у `DevMode` (только loopback, значок). (2) Оставить как есть: ставить локальный Keycloak из стенда.

**Следующий шаг.** Решить, нужен ли такой режим продукту (зависит от способа запуска у пользователей, `adr/0013`, открытые вопросы).
